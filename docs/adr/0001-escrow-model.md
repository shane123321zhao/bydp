# ADR-0001 保证金托管模型原则

- 日期：2026-09-23 · 状态：已采纳（原则）；P3 前定稿 · 裁定：PO
- 关联：架构 §8；HANDOVER 决策 5、10；审计 A2

## 背景
决策 5 "平台原则上不经手用户资金"，但先行赔付基金兜底与链上托管赔付都涉及资金触发权。若 BYDP 单方控制托管合约扣付权，实质构成托管+支付，在新加坡（PSA）、菲律宾等首发市场可能触发牌照问题。

## 决策
1. "不经手用户资金"的例外仅两项：先行赔付基金兜底（平台自有资金、单人/单案封顶）；链上托管的赔付触发。
2. BYDP 不得单方控制托管资金。P3 前在以下两种方案中定稿：(a) 多签 = 运营商 + BYDP + 独立第三方；(b) 合约按仲裁裁定哈希自动执行。
3. P3 前完成首发市场支付/托管牌照适用性法律核查。

## 备选与取舍
BYDP 单方控制：最简单，但牌照风险与公信力风险最大，否决。

## 后果
Payout 存链上交易哈希；Claim 必须关联 Complaint + Binding；P1 证据哈希算法（SHA-256）需现在定死以便 P3 锚定。
