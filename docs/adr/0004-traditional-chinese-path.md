# ADR-0004 繁体单路径取台湾口径

- 日期：2026-09-23 · 状态：已采纳（保守项，P2 前可改） · 裁定：PO（由 Cowork 会话取最保守选项，PO 已授权）
- 关联：架构 §11；HANDOVER 决策 12；审计 A11

## 背景
v1 一个 `/zh-hant/` 路径、一个 hreflang，术语表却分台湾与港澳两套口径，一个页面只能显示一套词。

## 决策
单一 `/zh-hant/` 路径（hreflang zh-Hant），页面用词取台湾口径；港澳口径词汇作为搜索同义词进入 Meilisearch 索引。P2 前评估是否拆为 zh-Hant-TW / zh-Hant-HK 双路径。

## 备选与取舍
双路径：SEO 更精准，但多一个语种的翻译、设计与维护成本；首发阶段不值，延后评估。

## 后果
i18n 资源只需一套繁体；术语表保留港澳列供搜索同义词与后期拆分；设计阶段文字长度测试只测台湾繁体。
