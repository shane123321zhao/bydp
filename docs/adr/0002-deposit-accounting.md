# ADR-0002 保证金账目分离与赔付优先

- 日期：2026-09-23 · 状态：已采纳 · 裁定：PO
- 关联：架构 §7 担保域、§8；HANDOVER 决策 9；审计 A3

## 背景
v1 允许"认证库佣金由保证金担保"，同一笔保证金既是用户赔付池又是平台佣金担保，用户会质疑平台拿赔付池抵自己的佣金；欠佣欠赔同时发生时优先级未定。

## 决策
Deposit 分两账目：用户赔付准备金、超额部分。用户赔付绝对优先；佣金担保只可动用超额部分；运营商同时欠佣欠赔时先赔用户。写入认证条款并在 `/certification` 页公开。

## 备选与取舍
单账目 + 事后协商：不可预期，损害"先行赔付保障"的公信力，否决。

## 后果
数据模型 Deposit 增加账目字段；商业护栏文案改为"由保证金超额部分担保"。
