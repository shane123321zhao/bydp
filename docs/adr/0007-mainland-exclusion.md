# ADR-0007 大陆排除：公示声明为主，TG 渠道不另做屏蔽

- 日期：2026-09-23 · 状态：已采纳 · 裁定：PO
- 关联：架构 §2、§10（`/regions`）；HANDOVER 决策 1；审计 A1

## 背景
审计指出 Web 层 IP 屏蔽对 TG Bot 无效（请求 IP 为 Telegram 服务器）。PO 裁定：Telegram 在中国大陆本身不可直接访问，已构成第一道过滤，不再叠加技术屏蔽。

## 决策
1. 全站、TG Bot 与所有终端常驻公示"不向中国大陆居民提供服务"声明（简/繁/英），并设 `/regions` 页说明服务地区。
2. Web 层保留大陆 IP 屏蔽（边缘 WAF + 应用层 `CF-IPCountry` 兜底），与语言逻辑解耦。
3. TG 渠道不做手机号国码或地区自证等额外屏蔽。

## 备选与取舍
Bot 要求 contact 分享拒 +86：转化损失大，PO 判断边际收益不值，否决。

## 后果
设计阶段增加"大陆排除声明条"组件与 `/regions` 页；Bot 首次交互文案含声明。

## 补注（2026-09-28，A-007 / W3#021）
本 ADR 的对象是**居民访问**（Web / TG）。`/v1/postback/*` 为运营商服务器对服务器调用、带 HMAC 鉴权、不面向居民，**豁免 451 地区屏蔽**；豁免路径须在 451 判定前记录结构化日志。其余路径不变。
