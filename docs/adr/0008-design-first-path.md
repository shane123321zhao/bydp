# ADR-0008 执行路径：设计先行、开发基建后移

- 日期：2026-09-23 · 状态：已采纳 · 裁定：PO
- 关联：HANDOVER 第 6 节计划 v3、决策 14

## 背景
PO 提出先做前端交互设计、数据层 mock：让投资人股东尽早看到可视化方案，早改早省；设计冻结后叠加已冻结架构，减少开发返工。架构师补充前置条件：设计必须有数据约束。

## 决策
1. 数据模型（架构 §7）在设计前冻结，作为设计硬约束；设计稿每个信任信号须标注实体.字段。
2. mock 数据存 `docs/design/fixtures/*.json`，实体与字段名严格对应 §7，覆盖边界样本，后期直接转为开发 seed。
3. 第 3 步只建最小仓库（git、docs、mailbox、精简 CLAUDE.md）；`apps/ packages/ .claude/` 开发基建在高保真冻结后建。
4. 高保真冻结 → API 契约定稿 → 完整骨架 → P1 拆解。

## 备选与取舍
先建全部开发骨架再设计：骨架会随设计返工，且投资人看不到东西；否决。
完全无数据约束的自由设计：会画出给不出数据的信任信号，违反项目纪律；否决。

## 后果
计划 v3 生效；设计阶段交付物增加 fixtures 与字段映射表。
