# ADR-0003 关联方处理：披露且永不认证、永不结佣

- 日期：2026-09-23 · 状态：已采纳 · 裁定：PO
- 关联：架构 §5、§8、§14；HANDOVER 决策 8；审计 A14

## 背景
创始人关联持牌平台与游戏工作室。v1 为"披露或不收录"。若关联方进入认证库并享赔付/结佣，即使披露仍是自评自赔，是公信力最脆弱点。

## 决策
关联方可收录并在品牌页与 `/disclosure` 页公开披露，但永不进入认证库、永不结算佣金、不接入优惠码通道的付费独家位。

## 备选与取舍
仅披露：合规上可行，公信力上不够硬，否决。不收录：损失用户查询价值，否决。

## 后果
Operator/Brand 增加 `related_party` 标记；scoring 与 tracking 均须读取该标记以硬拦截认证与结算。

## 补注（2026-09-26，M0 裁定 #8）
`relatedParty` 字段只落在 Operator 上，Brand 通过所属 Operator 继承；原文「Operator/Brand」指业务范围，不指两处存储。
