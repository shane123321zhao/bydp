# 隐私政策（草稿 v0.1 · 待 PO 审定 · 未上线）

## 1. 谁负责你的数据
「博弈点评」由【待替换：运营主体全称及注册地】运营，并负责处理你的个人数据。本政策参照新加坡《个人数据保护法》（PDPA）、马来西亚《个人数据保护法》（PDPA）与台湾《个人资料保护法》的要求撰写。

**我们的原则是：只收集提供服务所必需的数据；能存哈希的，不存明文；不出售你的数据，不做广告追踪。**

## 2. 我们收集什么
| 类别 | 内容 | 我们怎么存 |
|---|---|---|
| 登录身份 | Telegram 用户 ID，或你填写的邮箱 | 只存哈希与加密文本，不存明文 |
| 基本资料 | 显示名：由登录方式生成的打码名称（Telegram 为用户名前两位加 `***`，如 `@ab***`；无用户名时为 `TG ***` 加编号末两位；邮箱为打码邮箱）。**不保存**头像与真实姓名 | 正常存储，注销时清除 |
| 绑定账号 | 你在博彩平台的账号（自愿绑定，用于出款报告与赔付资格） | 只存哈希与加密文本；同一账号只能由一人绑定 |
| 投诉与证据 | 案件描述、金额、日期、上传的截图或文件 | 证据原文存放在对象存储中，仅仲裁员可以查看；每个文件都保存一份 SHA-256 哈希 |
| 评价与出款凭证 | 你提交的星级、评价文字；出款金额、方式、申请与到账时间、结果，以及上传的出款截图 | 先经人工审核，通过后才计入评分统计；评价文字不公开展示；出款截图存放在对象存储中，仅审核人员可以查看，每个文件都保存一份 SHA-256 哈希 |
| 积分与领码 | 领码 / 点击记录；平台回传的存款确认 | 平台回传的账号信息在收到时即转为哈希，不保存明文 |
| 偏好与通知 | 限额提醒、订阅、站内通知 | 正常存储，注销时删除 |
| 设备标识 | 随机设备编号（见第 9 节 Cookie） | 只存哈希 |
| 网络信息 | IP 地址、访问国家 / 地区 | 用于安全防护、限流和地区屏蔽；被查询次数的统计只保存 IP 网段的加密摘要，不保存 IP |
| 自我排除 | 排除档位、起止时间 | 只追加，不可修改 |

我们**不会**收集身份证件、银行卡号或手机号码，**不会**采集浏览器指纹，**不使用**广告或第三方统计 Cookie。

## 3. 我们用这些数据做什么
- 登录与账号安全：防止多账号滥用，支持「退出所有设备」；
- 受理与仲裁投诉，向被投诉平台发出通知，公开经脱敏的案件摘要；
- 计算评分（只使用统计结果，不公开到个人）；
- 发放优惠码、确认推广归因、计算积分；
- 执行自我排除、地区限制与反欺诈；
- 按你的设置发送站内通知、Telegram 消息或邮件。

## 4. 我们和谁共享
我们**不出售**你的个人数据。仅在以下情形与第三方共享，且只共享必要的部分：
- **基础设施服务商**：
  - Cloudflare：网络加速、安全防护、对象存储，以及加密备份的存放；
  - Resend：发送登录邮件与通知邮件；
  - Telegram：Telegram 登录与消息推送。
- **被投诉平台**：仲裁员通过平台的官方渠道人工通知案件，只提供答辩所必需的案件信息，**不提供你的登录身份、联系方式，也不提供你绑定的平台账号**（后台仲裁员只能看到绑定的核验等级，看不到账号本身）。
- **推广合作平台**：只用于归因。我们发给平台的是领码编号，平台回传的账号信息我们收到后即转为哈希。
- **AI 服务**：默认不使用。如果日后启用，送出前会先去除手机号、邮箱、账号等可识别信息，处理结果仅作为人工审核的参考。
- **法律要求**：在依法必须提供时，向有权机关提供。

## 5. 数据存放地与跨境传输
我们的服务器位于【待定：随生产落位确定】。Cloudflare 在全球多地设有节点，你的数据可能在你所在地区以外处理。我们对数据采取加密传输、加密存储与访问控制。

## 6. 保存多久
| 数据 | 保存期限 |
|---|---|
| 账号与资料 | 账号存续期间 |
| 已结案投诉的证据原文 | 你注销时删除（哈希保留） |
| 出款凭证截图原文 | 你注销或申请删除时删除（哈希保留） |
| 评价文字 | 你注销时清除；已通过审核的星级仍计入评分统计，但不再与你关联 |
| 案件状态日志、审计日志、证据哈希 | 只追加、长期保存，用于保证仲裁记录可信；你注销后不再与你关联 |
| 公开的案件摘要、评分统计、佣金账本 | 长期保存，你注销后不再与你关联 |
| 设备标识 | 注销后 180 天内删除 |
| 自我排除记录 | 长期保存（永久排除不因注销而失效） |
| 加密备份 | 最长保存 90 天后自动删除 |
| 邮箱登录链接 | 15 分钟后失效 |

## 7. 我们如何保护数据
- 敏感字段加密存储，身份与账号只以哈希形式用于比对；
- 运营后台不对公网开放，须经身份网关与两步验证；
- 后台操作按角色授权，并全部写入只追加的审计日志；
- 每日备份在离开服务器前已加密，解密私钥离线保管。

## 8. 你的权利
登录后在「我的 → 隐私与数据」可以申请：
- **导出**：获取我们保存的你的数据；
- **脱敏 / 删除证据原文**：删除你上传的证据原文，哈希保留；
- **注销（匿名化）**：清除你的身份、联系方式、偏好、订阅与通知，绑定失效、积分归零；评价文字清除、出款截图原文删除，尚未审核的评价与出款凭证不再处理；公开的案件摘要、状态日志、证据哈希与佣金账本会保留，但不再与你关联。

我们会在 **7 天内**处理申请。注销与删除需要二次验证，并有以下限制：
- 有**未结案投诉**时，需先结案或撤诉；未结案证据只能脱敏，不能删除原文；
- **自我排除期内**也可以注销，但同一 Telegram / 邮箱在排除期满前（永久排除则永不）不能重新注册。

如对处理结果有异议，你可以联系我们（第 12 节），也可以向你所在地区的个人资料保护主管机关投诉。

## 9. Cookie 与本地存储 {#cookies}
| 名称 | 用途 | 有效期 | 类型 |
|---|---|---|---|
| 登录会话 `__Secure-authjs.session-token` | 保持登录状态 | 7 天内有访问即续期，最长 30 天；退出即清除 | 必需 |
| 安全校验 `__Host-authjs.csrf-token` | 防止跨站请求伪造 | 浏览器会话 | 必需 |
| 登录跳转 `__Secure-authjs.callback-url` | 登录后回到原来的页面 | 浏览器会话 | 必需 |
| `bydp_did` | 随机设备编号，我们只保存它的哈希，用于发现同一设备上的多个账号；不采集浏览器特征，不用于广告 | 400 天；清除 Cookie 即重置 | 必需（安全） |
| 主题偏好（浏览器本地存储） | 记住你选择的配色，只保存在你的设备上，不发送给我们 | 直到你清除 | 功能 |

运营后台（仅限授权工作人员，独立子域）另有 `__Host-bydp-admin.session-token` / `__Host-bydp-admin.csrf-token` / `__Host-bydp-admin.callback-url`（作用同上，只在后台域名下）与 `bydp_admin_flash`（操作结果提示，15 秒）；普通用户不会收到。

我们不使用广告 Cookie，也不使用第三方统计 Cookie。

## 10. 未成年人
本站只面向年满 18 周岁的用户。如果我们发现某个账号属于未成年人，会注销该账号。

## 11. 政策变更
本政策发生重大变更时，我们会至少提前 7 天在站内公告。
