# PO 手工验收（D-022 · PO 待办 #25）

> 用你自己的**手机**和**电脑**各走一遍下面 5 条，约 30 分钟。每步写了「点哪里 → 看到什么算对」。
> 全部对就回「#25 done」；哪一步不对，截图并回「#25 第 X 条第 Y 步：看到了…」。
> 测试站地址 `https://staging.northx.vip`，第一次打开会先出现「测试环境 · 请输入访问口令」页：口令在你电脑的 `~/bydp-keys/staging-gate.txt`（Finder → 前往 → 前往文件夹 → 输入 `~/bydp-keys` → 用「文本编辑」打开复制，**不要发给任何会话**）。输入一次后同一浏览器 30 天内不再询问；手机和电脑各输一次。
> 邮箱登录链接请复制后粘贴到**已输过口令的同一个浏览器**里打开；邮件 App 自带的浏览器会再次要求口令。
> 测试站是演示数据，随便点、随便提交都不会影响正式站。

**开始前（一次）**：第 3、6 条需要登录。第 8 条「自我排除」会让账号 30 天内看不到优惠，**请用一个另外的邮箱登录来做第 8 条**，不要用你的 Telegram 主账号（它同时是后台管理员）。

## 第 1 条 · 查一个网址
1. 打开 `https://staging.northx.vip` → 看到首页大搜索框，提示「网址 · App · TG 号 · 收款地址」。
2. 输入 `jinlong88.com` 回车 → 跳到结果页，大字写着 **「可以存。」**，下面有「金龙娱乐城」品牌的链接。
3. 点品牌链接 → 进入品牌页：有圆形评分、绿色「认证」标签、黑色「前往官网」按钮。
4. 回到首页，输入 `jinlong99.com` 回车 → 大字 **「先别存。」**，下面有「你是不是要找」列出相近的品牌。
5. 再查 `cs-poker.net` → 大字 **「别存。」**；点「财神棋牌」品牌链接进品牌页：红底白字「黑名单」，**没有**「前往官网」和「专属优惠」。

**算对**：五句判定语只会出现这几种：「可以存。」「谨慎。」「先别存。」「别存。」「这是假的。」；手机上页面不能左右滑动、文字不能被截出屏幕。

## 第 3 条 · 领优惠码
1. 退出登录状态，打开 `https://staging.northx.vip/offers` → 每条优惠右下角「登录领码」。
2. 点「登录领码」→ 跳到登录页。
3. 用 Telegram 登录 → 自动回到优惠页，在「金龙娱乐城」那条优惠点「领码」→ 显示优惠码，旁边是「前往官网」或「官网链接待核验」。
4. 打开「我的」→ 「领过的码」数字 +1。

## 第 6 条 · 提交一件投诉
1. 登录后直接打开 `https://staging.northx.vip/complaint?b=jinlong`。
2. 第 1 步：投诉对象已选好「金龙娱乐城」→ 下一步。
3. 第 2 步：投诉类型选「提款延迟」，金额填 `100`，事件日期选今天，经过写一句「UAT 测试，请忽略」，证据选一张手机截图 → 「下一步 · 确认」。
4. 第 3 步：核对无误 → 「提交投诉 · 进入初筛」→ 跳到「我的案件」页，状态为初筛中。
5. 电脑上用你的管理员账号打开 `https://staging.northx.vip/admin/complaints` → 能看到刚才这件投诉，点开能预览你上传的截图。

**算对**：提交后马上能在「我的」里看到这件投诉；后台能看到；截图能打开。

## 第 8 条 · 自我排除（请用另一个邮箱账号）
1. 退出登录 → 登录页选「邮箱登录」，填你另一个邮箱 → 去邮箱点登录链接（15 分钟内有效）。
2. 打开「我的」→「负责任博彩」→ 排除时长选 **30 天** → 读红色提示 →「确认自我排除」。
3. 页面显示「自我排除中 · 至 某日」。
4. 打开 `/offers` → **看不到任何优惠**；打开金龙品牌页 → **没有**「前往官网」和「专属优惠」，有一行黄色提示。
5. 首页查 `jinlong88.com` 仍然能查；`/complaint?b=jinlong` 仍然能提交投诉。

**算对**：优惠、领码、前往官网全部消失；查验和投诉照常可用。

## 第 11 条 · 条款与隐私政策
1. 打开 `https://staging.northx.vip/terms` → 顶部有「草稿，上线前补全」提示，正文可读。
2. 打开 `https://staging.northx.vip/privacy-policy#cookies` → 页面直接跳到「Cookie」那一节。
3. 打开登录页 `https://staging.northx.vip/login` → 底部「隐私政策」链接点得开。

**算对**：三页都打得开，手机上不用左右滑动。
